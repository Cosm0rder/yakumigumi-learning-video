キャラクターと動きを切り替えながら、透過 PNG スプライトシートの再生を試せます。停止して1コマずつ確認したり、左右反転して画面の向きを合わせたりできます。

Gitから取得した場合は、プロジェクト直下で npm run pixel:build を実行してから開いてください。生成済み配布パックは展開後にそのまま再生できます。初回生成の手順
