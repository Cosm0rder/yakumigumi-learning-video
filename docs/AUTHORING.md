# 台本と図の編集

`examples/lesson.json` が最小の教材です。UTF-8のJSONとして保存します。scene/lineのidは重複しない英数字・ハイフン・アンダースコアにしてください。

```json
{
  "id": "my01",
  "kind": "lesson",
  "stage": "具体例",
  "title": "一画面で伝えたいこと",
  "action": "point",
  "visual": {
    "layout": "cards",
    "heading": "中心となる見出し",
    "items": [
      {"label": "前", "value": "100"},
      {"label": "後", "value": "200"}
    ],
    "note": "前提条件や短い補足"
  },
  "lines": [
    {"id": "a001", "speaker": "daikon", "text": "何が変わったの？"},
    {"id": "a002", "speaker": "shoga", "text": "この部分が2倍になったよ。", "say": "この部分がにばいになったよ。"}
  ]
}
```

`text` は画面の字幕、`say` は任意の読み上げ用表記です。`say`を変更しても音声は自動再生成されません。`narration`で書き出し、対応する音声ファイルを自分で差し替えます。

| speaker | キャラクター |
|---|---|
| shoga | しょうが |
| daikon | だいこん |
| garlic | にんにく |
| chili | とうがらし |
| negi | ねぎ |

## 図の種類

`cards`: 1〜3枚のカードが順に現れます。`steps`: カードの間に矢印が付きます。`bars`: `value`に0以上の数値を入れます。最大値との比率で棒が伸び、`unit`を数値に添えます。

`question` は `question`、`answer`、`revealAtLine` を指定します。`revealAtLine: 1` は2番目の台詞開始で答えを表示、という意味です。答えを隠す時間は最初の台詞の長さに連動します。

文字が長い場合は横方向に収まるよう調整されますが、読める大きさを保つため項目は短くしてください。自動で内容の正しさを判断する機能はありません。

## キャラクターの動き

sceneの `action` に `idle / wave / nod / think / point / cheer / walk / surprise` を指定できます。省略すると、しょうがの発話中は指さし、それ以外は待機します。

## タイミングと出力

- 実際の音声をローカルでデコードし、サンプル数から長さを計測します。
- 台詞の間には標準で0.35秒の間を入れます。
- 長い台詞の字幕切替は文字量による推定です。音素単位の自動同期ではありません。
- `output/timeline.json`、`subtitles.srt`、`chapters.txt` は全編の時刻です。
- `--from` と `--seconds` で部分動画を出した場合も、字幕ファイルは全編用です。部分動画を単独で公開する場合は字幕の時間を編集してください。

既存の宇宙演出は `kind` と特定の場面構成が結びついています。新しい教材では `lesson` から始め、複雑なシーンを追加するときはClaudeへの指示文を使って実装を拡張してください。
