PNG は全コマを収めたスプライトシートです。「個別フレーム」から1コマずつ保存できます。GIF は確認用、透過を保った動画素材には PNG / APNG が適しています。

ドット絵調の原画の輪郭には半透明部分があります。背景を切り替えて見え方をご確認ください。
