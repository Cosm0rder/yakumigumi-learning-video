# 音声を用意する

このキットはTTSサービスへ接続しません。APIキー入力欄もありません。録音済みファイルを使えば、AIサービスの契約も不要です。

## 自分の声で録音

`npm run narration` の出力を読み、1台詞ずつ録音します。先頭と末尾の長い無音を切って、`audio/l001.wav` など指定されたファイル名で保存します。

## Google AI Studioなどで作成

1. **利用者自身のアカウント**で [Google AI Studio](https://aistudio.google.com/) を開きます。
2. 画面に表示される音声生成機能を選び、その時点の無料枠・料金表示を確認します。このリポジトリは無料枠を保証しません。
3. `output/narration.txt` から台詞の本文だけをコピーします。IDや「保存名」まで読み上げさせないでください。
4. 声の指定例: 「可愛い女性アニメキャラクター。明るく聞き取りやすく、専門用語はゆっくり。文章だけを読み、前置きやBGMを付けない」。
5. 出来た音声をダウンロードし、指定されたIDのファイル名で `audio/` へ置きます。
6. 誤読、台詞の欠落、余計な挨拶、無音、声の取り違えがないか試聴します。

サービスのUIは変わるため、ボタン位置を固定した自動操作は同梱しません。サービスの利用条件に従って自分の音声を用意してください。原作者のAPI、Googleプロジェクト、課金枠、ログイン状態を再利用する機能はありません。

## 保存ルール

- 対応拡張子の優先順: `.wav`、`.flac`、`.mp3`、`.m4a`、`.ogg`。
- 同じIDのファイルを複数の形式で置かない方が分かりやすくなります。
- 1ファイル＝1台詞。1台詞180秒以内。長ければ分割してください。
- `audio/`はGit対象外です。声を作るたびに再実行せず、既存ファイルを使い回します。
- APIキーやログイン情報を、音声ファイル・JSON・プロンプトへ入れないでください。

BGMを使う場合は、配布元の権利条件・YouTube収益化の条件を確認してください。映画の曲が無料だとは限りません。
