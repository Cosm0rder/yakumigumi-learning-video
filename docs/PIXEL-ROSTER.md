## 新原画とアニメーションの扱い

新原画は ImageGen で制作したピクセル風のラスター画像です。多色や部分的な透明度を含み、手打ちのネイティブなドット格子で描かれた素材とは表記しません。受領した原画を保持し、動画やゲームで利用するフレームアニメーションは別のエントリとして追加します。

15体と上記の形状差分2種に、それぞれ描き分けた10種類のキーポーズを統合しました。待機・まばたき・歩行／移動・喜ぶ・驚く・困る・考える・話す・指さす／説明・おじぎの計170モーションを生成できます。Gitでは原画と正規化ポーズを保持し、再生用のシートやプレビューは `npm run pixel:build` で生成します。手足がないキャラクターは元の形状を守り、跳ねや傾きなどで動きを表現します。既存のしょうが8モーション素材とAPI不要のローカル動画出力は保持しています。

素材仕様と初回生成の手順は [PIXEL-ASSETS.md](PIXEL-ASSETS.md) を参照してください。
